# rtemis-org/homebrew-tap

Homebrew formulae for rtemis tools.

```sh
brew install rtemis-org/tap/rtemis-afm
```

| Formula | What it is |
|---|---|
| `rtemis-afm` | Bridge between [rtemislive](https://live.rtemis.org) and Apple's on-device Foundation Model. Apple silicon, macOS 27+. |

Formulae are written by each project's release workflow (for `rtemis-afm`,
`.github/workflows/release.yml` in
[rtemis-org/rtemis-afm](https://github.com/rtemis-org/rtemis-afm) fills in
`packaging/homebrew/rtemis-afm.rb.template` and commits it here as
`Formula/rtemis-afm.rb` on every tagged release). Edit the template there,
not the file here.
